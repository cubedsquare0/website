# Agents

This file lists the agents and tools used in the development of the Cubed Square website.

## Development Agents

- **GitHub Copilot**: AI-powered code suggestions and completions.
- **ESLint**: JavaScript linting for code quality.
- **Prettier**: Code formatting.

## Deployment Agents

- **Cloudflare Pages**: Frontend hosting.
- **Cloudflare Workers**: Backend API hosting.

## Monitoring Agents

- **Dependabot**: Automated dependency updates.
- **GitHub Actions**: CI/CD pipelines.

For more information on contributing agents, see [CONTRIBUTING.md](CONTRIBUTING.md).
